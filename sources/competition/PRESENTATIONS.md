## AURA-DELTAX presentation lesson

The presentation should not claim that a feature is strong merely because it exists in code. For each important capability, distinguish:

- **Implemented** — verified in source code.
- **Demonstrated** — visible in the demo/presentation.
- **Validated** — supported by reproducible testing/backtesting.
- **Claimed** — stated by the team but not independently verified.

This distinction should be preserved in the AURA-DELTAX competition analysis.
